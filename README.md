Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan.

This entry's joke (75 characters):

> I told my plants I'm rooting for them. They said, 'We're already grounded.'

`main.py` (pure Python standard library, no dependencies) validates the joke — non-empty, at most 200 characters, valid UTF-8 — and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Validate without writing:

```sh
python3 main.py --check
```
